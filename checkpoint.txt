PROJECT OVERVIEW
================================================================================

Cross-platform RSVP (Rapid Serial Visual Presentation) speed-reading app.
- Android: Jetpack Compose + Kotlin, C++ engine via JNI
- iOS: SwiftUI + Swift, C++ engine via C bridge (Swift C++ interop)
- Desktop: Qt 6 Widgets + C++

The C++ engine in core/rsvp_engine.hpp is the SINGLE SOURCE OF TRUTH for all
reading logic. Never re-implement tokenisation, ORP, or timing in platform code.

Full design spec is in AGENTS.md (read this first).

DESIGN SPEC REFERENCE (from AGENTS.md)
================================================================================

Colors:
  Background:     #0a0a0a
  Word text:      #e8e4dc, serif font (EB Garamond or system serif)
  ORP letter:     #c0392b
  Guide lines:    rgba(255,255,255,0.06)
  WPM badge:      monospace, rgba(255,255,255,0.22)

Touch gestures (Android + iOS):
  Tap           → play / pause
  Swipe left    → skip +8 words
  Swipe right   → skip −8 words
  Swipe up      → speed +25 WPM
  Swipe down    → speed −25 WPM
  Long press    → back to text input (600ms)

Keyboard (Desktop):
  Space         → play / pause
  Left/Right    → seek ±8 words
  Up/Down       → speed ±25 WPM
  Escape        → back to text input

Hard rules:
  1. core/rsvp_engine.hpp is header-only, zero external deps
  2. on_token fires on timer thread — MUST dispatch to UI thread
  3. C++17 only, no C++20
  4. No shared state between platforms
  5. UI code never touches timing math

C BRIDGE API REFERENCE (for iOS Swift files)
================================================================================

The C bridge (core/rsvp_bridge.h) exposes these functions:

  // Callback types
  typedef void (*rsvp_token_cb)(void* ctx, const char* before, const char* orp,
      const char* after, const char* punct, uint32_t idx, uint32_t total,
      uint32_t dur_ms, int sentence_end);
  typedef void (*rsvp_state_cb)(void* ctx, int state);  // 0=Idle,1=Playing,2=Paused,3=Done
  typedef void (*rsvp_done_cb)(void* ctx);

  // Lifecycle
  void* rsvp_create(void);
  void  rsvp_destroy(void* engine);

  // Playback
  void  rsvp_load(void* engine, const char* text, int wpm);
  void  rsvp_play(void* engine);
  void  rsvp_pause(void* engine);
  void  rsvp_toggle(void* engine);
  void  rsvp_seek(void* engine, int delta);

  // Speed / Progress
  void     rsvp_set_wpm(void* engine, int wpm);
  int      rsvp_get_wpm(void* engine);
  float    rsvp_progress(void* engine);
  uint32_t rsvp_cur(void* engine);
  uint32_t rsvp_total(void* engine);

  // Callbacks
  void rsvp_set_on_token(void* engine, rsvp_token_cb cb, void* ctx);
  void rsvp_set_on_state(void* engine, rsvp_state_cb cb, void* ctx);
  void rsvp_set_on_done(void* engine, rsvp_done_cb cb, void* ctx);

ENGINE API REFERENCE (for Android/Desktop)

  rsvp::Engine engine;

  engine.on_token = [](const rsvp::Token& t, size_t idx, size_t total) { ... };
  engine.on_state = [](rsvp::State s) { ... };
  engine.on_done  = []() { ... };

  engine.load(text, wpm);    // tokenise + set speed
  engine.play();
  engine.pause();
  engine.toggle();
  engine.seek(delta);        // +n forward, -n backward
  engine.set_wpm(wpm);       // live speed change
  engine.wpm();              // get current WPM
  engine.progress();         // 0.0–1.0
  engine.cur();              // current word index
  engine.total();            // total word count
  engine.state();            // State::Idle/Playing/Paused/Done

  rsvp::Token has: before, orp, after, punct (strings), dur_ms, sentence_end
